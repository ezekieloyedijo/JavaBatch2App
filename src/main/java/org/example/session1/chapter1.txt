SCHOOL MANAGEMENT SYSTEM

You are building a School Management System with the following entities:

Student
Teacher
Course

Requirements:
You must store all students and be able to find any student quickly using their ID
A course can have multiple students, but a student must not be registered twice in the same course
The system should maintain a list of courses in the order they were created
A teacher can teach multiple courses
You should be able to:
Register a student into a course
Assign teachers to courses
View all students in a course

TASK
Choose between List, Set, and Map for each requirement
Explain why you chose each data structure
Implement using:
entity
repository
service
controller (Main class)

Use Case	Data Structure	Reason
Store all students	Map<Integer, Student>	Fast lookup by ID (O(1))
Students in a course	Set<Student>	Prevent duplicates automatically
Courses	List<Course>	Maintain insertion order
Teachers in a course	List<Teacher>	Order may matter, duplicates allowed
